# Dashboard Power BI

Salve aqui o arquivo `dashboard.pbix` exportado do Power BI Desktop, com as páginas:

1. **Visão Executiva** — cards (estoque total, valor do estoque, cobertura média, SKUs em
   risco, SKUs em excesso), distribuição de SKUs por situação, evolução de vendas,
   ranking dos maiores riscos.
2. **Desempenho de Vendas** — evolução por curva, top produtos/fornecedores, mapa de
   calor de sazonalidade.
3. **Estoque, Curva e Fornecedores** — cobertura por curva, matriz de risco, nível de
   serviço por fornecedor, dispersão estoque x venda.
4. **Previsão de Demanda** — real vs. previsto, previsão x estoque disponível, ranking de
   crescimento projetado.

Depois de publicar no Power BI Service, adicione o link de acesso também no README.md
principal e no relatório da Fase 2 (seção 3).
